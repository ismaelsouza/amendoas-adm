# Casa das Amêndoas

- Ao retomar o projeto, leia [Essentials](ESSENTIALS.md) para recuperar o contexto dos dois canais, as decisões confirmadas e o trabalho em aberto.
- Antes de implementar uma regra em discussão, confira a Issue indicada e valide a decisão com o responsável pelo processo.
- Ao fechar ou alterar uma decisão, atualize `ESSENTIALS.md` no mesmo trabalho. Registre a data, a regra, o motivo quando conhecido, a evidência da confirmação e a Issue. Se a regra mudar, identifique a decisão substituída no histórico.
- Antes de encerrar uma sessão com avanço no projeto, atualize as pendências e o próximo passo. Se uma alteração for publicada no GitHub, verifique a branch ou o pull request para que outra máquina consiga recuperá-la.
- Use exemplos fictícios nos arquivos versionados. Mantenha senhas, chaves e registros reais de clientes fora do Git.
