# Documentação de domínio

Este repositório tem um contexto de domínio. Antes de explorar uma regra, leia `GLOSSARY.md` na raiz e os ADRs relacionados em `docs/adr/`, se existirem. Consulte o [Essentials](../../ESSENTIALS.md) e a Issue indicada para saber o que foi aprovado.

Use os termos do glossário nas Issues, no código e nos testes. Se uma proposta contrariar um ADR, indique a decisão que precisa ser reaberta. Quando um termo ou uma decisão for confirmado, registre-o com `domain-modeling`.
