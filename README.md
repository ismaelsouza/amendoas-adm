# amendoas-adm

Sistema administrativo da Casa das Amêndoas. A primeira versão, **Essentials**, reúne os pedidos dos vendedores e do balcão e acompanha estoque, entregas e faturamento.

O código em desenvolvimento está na [branch `develop`](https://github.com/ismaelsouza/amendoas-adm/tree/develop). O [app do vendedor](https://github.com/ismaelsouza/amendoas-app) tem repositório próprio.

Consulte o [registro do Essentials](ESSENTIALS.md) para recuperar o contexto. As discussões anteriores continuam no [mapa de decisões](https://github.com/prpaulocesarneves-crypto/amendoas--adm/issues/1) do repositório de origem.
