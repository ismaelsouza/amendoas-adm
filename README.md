# amendoas--adm

Sistema administrativo da Casa das Amêndoas. A primeira versão, **Essentials**, reúne os pedidos dos vendedores e do balcão e acompanha estoque, entregas e faturamento.

Comece pelo [registro do Essentials](ESSENTIALS.md) para recuperar o contexto, as decisões e as pendências. Consulte o [mapa de decisões no GitHub](https://github.com/prpaulocesarneves-crypto/amendoas--adm/issues/1) para acompanhar as discussões. O [app do vendedor](https://github.com/prpaulocesarneves-crypto/amendoas-app) tem repositório próprio.
